# CRIMA Ontology Website on GitHub Pages

This repository contains the source files (under the `/docs` directory) for the static website of the [CRIMA Ontology](https://github.com/crima-ontology/ontology), published via [GitHub pages](https://docs.github.com/en/pages) at

https://crima-ontology.github.io/

## Acknowledgements

The CRIMA ontology and related material, including this website, were developed within the *CRIMA project* (Evidence-based Management of Climate Risks), funded by the *European Regional Development Fund (ERDF/FESR)*.

The CRIMA project supports evidence-based climate risk assessment by integrating Earth Observation data, scientific knowledge, and semantic technologies.

Project website: [crima.eurac.edu](https://crima.eurac.edu/)
